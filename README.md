# NOVA Store - E-Commerce QA Portfolio

## Project Overview

NOVA Store is a responsive e-commerce demo website created as a Software Testing and QA portfolio project.

The project provides a realistic shopping experience that can be used to practice and demonstrate different software testing techniques.

## Main Features

- User Registration and Login
- User Profile
- Product Browsing
- Product Search
- Product Filtering and Sorting
- Product Details
- Wishlist
- Shopping Cart
- Coupon Validation
- Checkout
- Order Confirmation
- Order History
- Responsive Design for Desktop, Tablet, and Mobile
- Form Validation
- Error and Empty States

## Testing Scope

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start testing the main user flows.

## Main Testing Flows

### Registration and Login

Register a new user, log in, view the profile, and log out.

### Product Discovery

Search for products, apply filters, sort results, and open product details.

### Shopping Cart

Add products to the cart, change quantities, remove products, and apply coupons.

### Checkout

Complete the checkout form and verify order confirmation and order history.

### Responsive Testing

Verify the website on desktop, tablet, and mobile screen sizes.

## Project Purpose

This project was created to demonstrate practical QA skills including test case design, defect reporting, test planning, regression testing, and end-to-end testing.
